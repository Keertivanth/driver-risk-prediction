# Driver Risk Prediction

Machine-learning project for predicting driver risk.

## Project layout

- `data/`: raw and processed datasets
- `notebooks/`: exploration and experimentation notebooks
- `src/`: reusable preprocessing, training, evaluation, and prediction code
- `models/`: serialized trained models
- `reports/figures/`: generated visualizations

Place the source dataset in `data/raw/driver_risk.csv` before running the pipeline.
